# Admin

Scope: `/admin` (login, IGDB search and results, Import with slug-collision prompt, invalid-row list, Catalog list, Sync, Sync all, Remove, status and error messages). Mode: **Operate**. English only.

Task: one owner, a few times a month, on a laptop: find a Game on the Source and Import it, Sync one or all, Remove, fix invalid rows in the Sheet. Precision and calm over expression; the Catalog has under 50 Games.

Inherits the public site's world (Prussian ink masthead, the same tokens; Archivo carries all UI text, Source Serif 4 only the occasional sentence of prose). Destructive actions (Remove, Sync all overwriting hand edits) are visually distinct from routine ones; status messages use the same mark-not-hue rule as the public site.
