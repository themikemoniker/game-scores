# Admin

Scope: `/admin` (login, IGDB search and results, Import with slug-collision prompt, invalid-row list, Catalog list, Sync, Sync all, Remove, status and error messages). Mode: **Operate**. English only.

Task: one owner, a few times a month, on a laptop: find a Game on the Source and Import it, Sync one or all, Remove, fix invalid rows in the Sheet. Precision and calm over expression; the Catalog has under 50 Games.

Inherits the public site's Cross Review Weekly world at Operate volume: the yellow masthead band and black rules, the same tokens and Score circles; Zen Kaku Gothic New carries all UI text and Dela Gothic One only the wordmark and section titles. Destructive actions (Remove, Sync all overwriting hand edits) are visually distinct from routine ones; status messages use the same mark-not-hue rule as the public site.
