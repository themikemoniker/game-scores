# 11: CI

**What to build:** A GitHub Action that runs `npm run typecheck`, `npm test` and `npm run build` on every pull request and on every push to `main`, so a broken change shows up as a red check before it merges, next to Vercel's preview deploy.

See `.scratch/game-scores/spec.md`: user story 58, and CI.

**Blocked by:** none

**Status:** in progress

- [ ] `.github/workflows/ci.yml` runs on `pull_request` and on push to `main`, on Node 24 with the npm cache.
- [ ] It runs `npm ci`, `npm run typecheck`, `npm test` and `npm run build`, and needs no repository secrets.
- [ ] The workflow runs green on its own pull request.

## Comments

- The build needs no secrets: every route is rendered on demand, so `next build` never reads the Sheet or calls IGDB. Checked by building a clean checkout with the Google variables unset.
- Making CI a required check is a repository setting, left off until there's a second regular contributor.
